What is PCE?
Post-Course Evaluation as curriculum intelligence layer

Post-course evaluation is how healthcare programs measure quality + close the accreditation loop. Students rate didactic courses; faculty reflect on teaching. Data combines with exam performance + placement competency to answer the core accreditor question: "How do you know your curriculum is working?"

Exxat's competitive advantage: Only Exxat connects course eval → exam performance → competency verification. This data integration is impossible in siloed systems (Anthology + ExamSoft + Canvas).

Two-Instrument Architecture
Why two separate surveys instead of one unified form?
Instrument 1
Student PCE (Course Evaluation)
What: Students rate course content, teaching quality, learning outcomes
Routing: Responses go to Faculty, Program Director, Dean
Why separate: Student feedback is distinct from faculty reflection; separate surveys improve response clarity
Instrument 2
Faculty Reflection (Self-Assessment)
What: Faculty reflect on course effectiveness, student performance, teaching adjustments
Routing: Responses go to Program Director only (not to students or dean)
Why separate: Faculty self-assessment is developmental; sharing directly with students creates defensiveness
Aspect Student PCE Faculty Reflection Rationale
Questions 10-12 Likert + 2 open 8-10 Likert + 2 open Different purposes → different questions
Recipients Faculty, Program Dir, Dean Program Dir only Student feedback shared broadly; faculty reflection confidential
Response rate baseline 50-70% (incentivized) 80-90% (mandatory) Faculty compliance high; student participation requires incentive
Expected response time 5-8 min 8-12 min Faculty reflection requires more thought
Why: One unified survey creates confusion about routing + purpose. Two instruments clarify intent: "You're giving feedback to improve teaching" (student PCE) vs "You're reflecting on your teaching" (faculty reflection). Separate instruments also allow different question sets optimized for each audience.
Three Analytics Dimensions
How Program Directors visualize PCE data
Dimension 1: By Term (What's our trend?)
Program Director views: Fall 2025, Spring 2026, Fall 2026 side-by-side
KPIs at top: Response rate, avg satisfaction score, faculty count
Charts: Response rate trend, average score trend (line chart with YoY comparison), course satisfaction heatmap
Action: "Pharmacology satisfaction dropped from 4.2 to 3.1. Why? Who teaches it?"
Dimension 2: By Faculty (Who's performing?)
Program Director views: Leaderboard of faculty by satisfaction score
Top view: Ranked list (Dr. Smith: 4.5, Dr. Jones: 3.9, Dr. Brown: 3.2)
Drill-down: Click faculty → see term-by-term breakdown + comments
Action: "Dr. Brown needs support. Is this a new course? Can we pair with Dr. Smith?" (mentorship trigger)
Dimension 3: By Course (Which courses need revision?)
Program Director views: Longitudinal course performance
Top view: All courses ranked by avg satisfaction over last 3 terms
Drill-down: Click course → see faculty rotation + trends + student comments
Action: "Anatomy consistently scores 3.2. Content revision needed or teaching issue? Let's investigate."
Why: Three dimensions serve different decisions. "By Term" answers "Are we trending up or down?" "By Faculty" answers "Who's struggling?" "By Course" answers "What content needs revision?" All three data exists; organizing it into user decision-making lenses makes it actionable.
Distribution Workflow (Highest Design Investment)
How surveys get to students and faculty
Step 1
Academic calendar configured
Program admin sets term dates, course schedule, faculty assignments in system
Step 2
Survey templates auto-generate
Based on calendar + course config, system auto-creates student PCE + faculty reflection for each course. Faculty can customize template or use default.
Step 3
Distribution window opens (last week of course)
System sends survey to students + faculty. Reminders: Day 1, Day 3, Day 5. Faculty response due before grades posted (hard stop).
Step 4
Results dashboard live (within 24 hours)
Student PCE results visible to faculty + Program Director. Faculty reflection visible to Program Director only. Narrative synthesis (AI themes) auto-generated.
Step 5
Curriculum loop closes (accreditation document updated)
Program Director exports PCE data + exam performance + competency data into accreditation self-study. One click, not manual Excel.
Why: Distribution is the highest design investment because it's where students/faculty actually use the system. If survey delivery is complicated, response rates tank. Calendar integration + auto-template generation + smart reminders = high engagement.
