## A. S1 content close-out

### A1. `src/data/taxonomy.ts` (new)
- Four-level severity rubric with written, testable definitions:
  - **critical** — blocks a launch gate, compliance requirement, or named pilot; or causes users to
    leave the platform for external tools.
  - **high** — recurring workflow pain for a primary persona with no workaround inside the product,
    or a named competitive loss driver.
  - **medium** — friction with a workaround, single-persona annoyance, or improvement with clear
    but bounded value.
  - **low** — polish, preference, edge case, or observation with no current decision attached.
- Numeric weights for scoring: severity `{critical 4, high 3, medium 2, low 1, na 0}`,
  evidence class `{DIRECT QUOTE 3, SYNTHESIS 2, HYPOTHESIS 1}`,
  persona priority `{very-high 3, high 2, medium 1}` (from `PERSONAS[].priority`; insights with no
  persona use 1.5, the mean, so unassigned evidence is neither privileged nor buried).
- Single-source facts live here too: `COHERE_LAUNCH` (see A2).

## B. P7 design track

### B1. `src/lib/score.ts` (new) — opportunity scoring engine (D6)
`score(insight) = sevWeight × evidenceWeight × personaWeight`, returning
`{ total, parts: { severity, evidence, persona } }` so every consumer can render the formula.
Max 4×3×3 = 36. Inspectable everywhere it ranks: the UI shows `4×3×2 = 24`-style breakdowns,
never a bare number.
- `OverviewView` design-next queue: rank by score (recency as tiebreak), each row shows the
  breakdown chip; queue title updated to say "ranked by opportunity score".
- `SignalsView` / `computeAllSignals`: signal rank gains a summed-score dimension
  (`scoreTotal` on `ComputedSignal`), replacing pure topSeverity+count ordering.

### B2. EvidencePanel L2 → insight-as-document (D3 + D4)
`InsightCardV2` expanded state becomes document anatomy per the Dovetail directive:
serif title line (the `soWhat` or first sentence) at ~19–20px inside the 460px panel, one-line
summary, mono contributor+date row, then evidence as **highlight spans**: the pull quote rendered
as a tinted span (`--accent-bg`-style wash keyed to evidence-class color at low alpha) with the
evidence-class chip attached inline, not a detached blockquote. Score breakdown chip in the meta
row. Footer gains "Related" — up to 3 insights sharing a product + tag, each a jump link within
the panel. L3 action row unchanged. Collapsed state unchanged (density preserved).

### B3. Briefings computed live
`briefings.ts` static paragraphs replaced by builders that assemble each audience's
problem/findings/recommendation from live data: product stats (`PRODUCTS`), computed signals
(top by summed score), top-scored insights' `soWhat` lines, `COHERE_LAUNCH` (with conflict note
for Arun's evidence-grounded register), quote-coverage and severity-distribution stats.
`SIGNAL_RISKS` derived from top-scored signals + hard-deadline milestones. Exit test: zero static
prose paragraphs remain in `briefings.ts`; every sentence traces to a data field.
Register rules preserved: Arun evidence-grounded, Kunal business-outcome, Aarti decision-only.
